# Divengine Knowledge

Structured engineering knowledge items, references and taxonomies.

## Responsibilities

- Define taxonomy vocabularies for engineering knowledge classification:
  - **Knowledge Domain**: requirements, architecture, security, testing, etc.
  - **Knowledge Source Type**: standard, methodology, article, decision, etc.
  - **Standard Body**: ISO, IEEE, IEC, NIST, OMG, etc.
- Provide the foundation for knowledge-referencing in artifacts and traces.

## Dependencies

- divengine_core
- Drupal core: taxonomy, text, options

## Related Modules

- divengine_artifact — artifacts reference knowledge taxonomies.
- divengine_traceability — traces link knowledge to artifacts.

## Future Iterations

- Knowledge item content entity with full revision and moderation support.
- Knowledge graph relationships.
- Import from external standards catalogs.
